Migrate the IO Platform Python monolith to .NET 10 microservices with CLEAN architecture. Create 4 independently deployable domain services (IO.Proxy, IO.Common, IO.Cass, IO.Elsa) using USXpress infrastructure standards. Maintain existing API contracts and business logic while improving observability, scalability, and maintainability.
