# Quickstart: IO Platform .NET 10 Migration

**Feature**: 001-dotnet10-migration  
**Branch**: `001-dotnet10-migration`  
**Generated**: 2026-03-31

## Prerequisites

- .NET 10 SDK (latest preview or RC)
- Docker Desktop
- Access to USXpress NuGet feed
- MongoDB Atlas connection (or local MongoDB for dev)
- Kafka broker access (or local Kafka for dev)
- Azure AD credentials (for auth testing)

## Repository Setup

```bash
# Clone and checkout feature branch
git checkout 001-dotnet10-migration

# Verify structure
cd dotnet/
ls -la
```

## Build All Services

```bash
# From repository root
dotnet build dotnet/io-platform.sln

# Or build specific service
dotnet build dotnet/src/Apps/RestAPI/IO.Proxy/IO.Proxy.csproj
```

## Run Locally

### Option 1: Docker Compose (Recommended)

```bash
# Start all infrastructure and services
docker-compose -f dotnet/docker-compose.yaml up --build

# Services available at:
# - IO.Proxy: http://localhost:8080
# - IO.Common: http://localhost:8081
# - IO.Cass: http://localhost:8082
# - IO.Elsa: http://localhost:8083
# - IO.Larry: http://localhost:8084
# - IO.Lea: http://localhost:8085
```

### Option 2: Individual Services

```bash
# Terminal 1: Start IO.Proxy (API Gateway)
cd dotnet/src/Apps/RestAPI/IO.Proxy
dotnet run

# Terminal 2: Start IO.Common
cd dotnet/src/Apps/RestAPI/IO.Common
dotnet run --urls "http://localhost:8081"

# Repeat for other services...
```

## Integration with 002 TokenFactory

The XAuthTokenFactory from 002-xauth-token-factory is already integrated:

```bash
# Generate a scoped token (for testing)
curl -X POST http://localhost:8080/api/auth/token \
  -H "Authorization: Bearer $XAUTH_MASTER_TOKEN" \
  -d '{"scope": "io:common:read"}'

# Use scoped token
curl http://localhost:8080/api/common/email \
  -H "Authorization: Bearer <scoped-token>"
```

## Development Workflow

### Adding a New Endpoint

1. Define contract in `contracts/io-{service}-api.yaml`
2. Create request/response models in `src/Common/Models/`
3. Implement handler in service's `Core/` layer
4. Add endpoint in service's `Program.cs`
5. Write unit tests in `tests/unit/`
6. Update this quickstart if needed

### Clean Architecture Reminder

```
Request → API Layer → Core (Business Logic) → Infrastructure → External Service
             ↓              ↓
        Validation    Domain Rules
```

- **Core**: Business logic, interfaces, domain rules
- **Infrastructure**: External integrations (MongoDB, Kafka, HTTP clients)
- **Models**: Shared DTOs and entities
- **API**: Minimal endpoints, middleware, configuration

## Troubleshooting

### MongoDB TLS Issues

```bash
# Verify certificate path in appsettings.json
# Download MongoDB Atlas certificate if needed
curl -o mongopem/ atlas.pem https://... 
```

### Kafka Connection

```bash
# Verify topic exists
kafka-topics.sh --list --bootstrap-server localhost:9092

# Create topic if missing
kafka-topics.sh --create --topic vendor-lookup-sync --bootstrap-server localhost:9092
```

### Token Validation Fails

```bash
# Check XAUTH_MASTER_TOKEN is set
echo $XAUTH_MASTER_TOKEN

# Verify middleware is registered in Program.cs
# Check token hasn't expired
```
